# Cover certificates: m(53) k=13 and m(59) k=14

These directories contain a checked SAT certificate that our previously retained
per-cube UNSAT proofs (M53CERT for `p=53, k=13`; CERTRUN5/CAKEREPLAY for `p=59, k=14`)
cover the whole search space, not just some subset of it. Before this, coverage of the
`2^14 = 16,384` sign-pattern partition was established by construction (the code that
enumerated all sign patterns on membership variables `x_2..x_15`). It is now also a
machine-checked certificate: kissat, drat-trim, and cake_lpr all agree that

```
base CNF AND (for every retained cube C: NOT C)
```

is UNSAT, i.e. no model of the base formula lies outside the 16,384 listed cubes.

## Credit

The cover-certificate scheme and reference implementation (`cover_cert.py`,
`check_cover.py`) are by Pawel Kwaczynski, MIT license:
https://github.com/pawelkwaczynski/unique-sum-free-cert (commit `2586c70791fa84e9a5805fc432a26b205ce8f496`).
The construction follows the pattern in Szeider's LRAT-Catcher paper: the completeness
of a cube partition is refuted by a SAT solver and the refutation is checked by
drat-trim and cake_lpr, rather than trusted from the generating code alone.

Our adaptation (`ops/cover-cert.py`) is a from-scratch implementation of the same idea
against our own toolchain and cube ledgers; it is not a copy of Pawel's code.

## What is in each directory

For each of `m53-k13/` and `m59-k14/`:

- `p53-k13.cnf` / `p59-k14.cnf`: the base CNF, generated by the pinned encoder
  (`ops/usf_encode_pinned.py` in the private repository, sha256
  `2eeec8ec926f80ee0d9db55a4f396acc3fe92110cc9bfc78908260a53b1c9003`) at the stated
  `(p, k)`.
- `cubes.dimacs`: the 16,384 retained cubes, normalized to one DIMACS cube per line.
- `cover.cnf`: the base CNF plus one clause `NOT C` per cube (the completeness formula).
- `cover.drat`, `cover.lrat`: the solver's refutation proof and its LRAT translation.
- `kissat.log`, `drat-trim.log`, `cake_lpr.log`: raw tool output.
- `report.json`: hashes, exit codes, verdicts, and per-tool runtimes.
- `SHA256SUMS`: hashes of every file in the directory (including itself excluded).

## Verdicts

Both certificates passed:

- **m53, k=13**: `PASS`, kissat rc=20 (0.690s), drat-trim `s VERIFIED` (0.298s),
  cake_lpr `s VERIFIED UNSAT` (0.073s). Summed tool runtime 1.062s.
- **m59, k=14**: `PASS`, kissat rc=20 (0.669s), drat-trim `s VERIFIED` (0.304s),
  cake_lpr `s VERIFIED UNSAT` (0.080s). Summed tool runtime 1.053s.

Both certificates cover a single, non-recursive top-level cube list: the full
`2^14` sign-pattern partition, with no parent/child split.

## Reproduce

With `kissat`, `drat-trim`, and `cake_lpr` on `PATH` (or passed explicitly):

```sh
python3 ops/cover-cert.py m53-k13/p53-k13.cnf m53-k13/cubes.dimacs --out-dir /tmp/check-m53
python3 ops/cover-cert.py m59-k14/p59-k14.cnf m59-k14/cubes.dimacs --out-dir /tmp/check-m59
```

Each should print `PASS: complete cover, kissat rc=20 (...); drat-trim rc=0 s VERIFIED
(...); cake_lpr rc=0 s VERIFIED UNSAT (...)` and reproduce the `cover.cnf`,
`cover.drat`, and `cover.lrat` hashes recorded in the corresponding `report.json`.

To regenerate the base CNFs from the pinned encoder directly:

```sh
python3 ops/usf_encode_pinned.py 53 13 > p53-k13.cnf   # sha256 b4dc490bfae1506d76...
python3 ops/usf_encode_pinned.py 59 14 > p59-k14.cnf   # sha256 fa985c9d2c2cf1aaa72...
```

The full per-cube proof archives (CNF/DRAT/LRAT for each of the 16,384 leaves) are
retained separately and are not part of this bundle; this bundle certifies only that
the leaf list is a complete cover of the base search space.
